EXPEDIENTE #LOG-01 // RESUELTO

Rescate Térmico y Mantenimiento Crítico

[ 01. EL PROBLEMA ]

Equipos administrativos y de laboratorio presentaban apagados repentinos y lentitud extrema debido a acumulación de polvo y pasta térmica seca.

[ 02. CÓMO LO SOLUCIONÉ ]

Se ejecutó un protocolo de mantenimiento preventivo por lotes: limpieza interna con aire comprimido, reemplazo de pasta térmica de alto rendimiento, verificación de voltajes en fuentes de poder y optimización de arranque del sistema operativo.

Mantenimiento Preventivo Diagnóstico de Hardware Optimización SO
EXPEDIENTE #LOG-02 // RESUELTO

Reestructuración de Racks y Sistema NVR

[ 01. EL PROBLEMA ]

Cableado desordenado en el site principal dificultaba identificar fallos de red y provocaba pérdida intermitente de señal en cámaras de seguridad.

[ 02. CÓMO LO SOLUCIONÉ ]

Se etiquetaron todas las líneas UTP, se realizó el peinado estructurado hacia los switches y el patch panel, y se reconfiguraron las direcciones IP estáticas del NVR para garantizar grabación continua 24/7.

Cableado Estructurado Switches Videovigilancia NVR
EXPEDIENTE #LOG-03 // RESUELTO

Recuperación de Plataforma Moodle bajo Presión

[ 01. EL PROBLEMA ]

Corrupción en tablas críticas de la base de datos dejó inaccesible el aula virtual en pleno periodo de evaluaciones.

[ 02. CÓMO LO SOLUCIONÉ ]

Acceso vía SSH al servidor, aislamiento del servicio web, reparación de tablas dañadas en MariaDB/MySQL y validación de integridad de respaldos, logrando restablecer el acceso completo en menos de 45 minutos sin pérdida de calificaciones.

MySQL / MariaDB SSH & Linux Administración Moodle
EXPEDIENTE #LOG-04 // RESUELTO

Automatización de Control Escolar y Correo

[ 01. EL PROBLEMA ]

Las notificaciones automáticas del portal escolar caían en spam o no llegaban a los alumnos, generando saturación en ventanilla administrativa.

[ 02. CÓMO LO SOLUCIONÉ ]

Implementación de autenticación SPF/DKIM en el dominio, configuración de WP Mail SMTP y redacción de guías visuales simples para que el personal administrativo operara el sistema con total autonomía.

EdTech WP Mail SMTP Gestión Administrativa
